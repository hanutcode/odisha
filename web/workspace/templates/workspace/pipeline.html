Pipeline

Each button runs the same step as the command line. Order: extract → build panel (the crosswalk is rebuilt with it) → review names.

StepWhat it does
Extract raw dataReads NFHS-4/5 fact sheets, NCRB, UDISE+, Odisha reports and detection capacity into tidy tables. NFHS-6 fact sheets load the same way. {% include "workspace/_runbtn.html" with step="extract" %}
Extract rainfall and night lightsDistrict averages from CHIRPS and VIIRS rasters, plus the rainfall-shock score. Slow: a minute or more per year. {% include "workspace/_runbtn.html" with step="extract_rasters" %}
Build crosswalkHarmonised district units from the LGD export and splits. Lists problems for the Crosswalk review page. {% include "workspace/_runbtn.html" with step="crosswalk" %}
Build panelRebuilds the crosswalk, matches every district name and writes the 2015–2024 panel. Refuses to run if NFHS-6 leaks in. {% include "workspace/_runbtn.html" with step="panel" %}
Rebuild mapRegenerates the Odisha map from the current model outputs. {% include "workspace/_runbtn.html" with step="demo" %}
